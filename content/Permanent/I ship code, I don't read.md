[I ship code I don't read](https://newsletter.pragmaticengineer.com/p/the-creator-of-clawd-i-ship-code)

코드를 읽지 않고 배포하는 시대가 왔다.

챗지피티가 처음 나오고 코파일럿으로 코딩하던 시절에 '3년 후에는 개발자 다 대체되는거 아니야?' 라고 설마 그러겠어 라는 심정으로 말하고 다녔는데, 진짜로 거의 그렇게 되어버렸다.

개발자가 코딩하는 사람이라면 이제 대체되었다고 봐도 무방하다. 직접 코드를 짜는 것은 안한지 오래되었으니까. 이 흐름은 되돌릴수도 없고 멈출 수도 없다. 작은 기업부터 점점 대기업까지 코드 짜는 직업이라는 것은 사라질 것이다.

우리는 가치를 제공하면서 만족감을 느끼고 보상을 얻으며 살아간다. 언제나 그랬듯, 우리는 가치 생성자여야 한다. 지금까지는 코드 생성의 가치가 컸다. 하지만 이제는 코드 생성의 가치는 점점 줄어 들고 있다. 다른 분야도 마찬가지로 AI가 발달하면서 점점 인간이 생산하는 가치는 점점 줄어들것이다.

내가 가장 가치를 많이 생산할 수 있는 걸 꾸준히 찾고 움직여야한다.
